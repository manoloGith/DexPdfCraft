# Opciones de icono

Cinco diseños originales de DexPdfCraft para elegir (SVG, lienzo de icono adaptativo de 108 dp con
el dibujo dentro de la zona segura de 66 dp). `opciones.png` los muestra con las máscaras de Android
y en tamaño de barra de tareas. No usan nada de Adobe ni los logotipos de ArtCraft.

1. Página y monitor: un PDF en el escritorio (DeX)
2. Página con pluma: leer y editar
3. Páginas en ventanas: multitarea, con «PDF»
4. Monograma «D»: una página doblada que forma la D
5. Página con lupa: buscar y revisar

El elegido se convierte en el icono adaptativo de la app (fondo y primer plano vectoriales); el
resto puede borrarse.
